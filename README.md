## Resumen ejecutivo

Esta ruta está estructurada en bloques de aprendizaje para seguir una progresión lógica desde los fundamentos de sistemas hasta áreas más especializadas como kernel, seguridad, IA, web, móvil, graphics, blockchain y compiladores.

Se han excluido los proyectos del common core antiguo y nuevo, así como los elementos no técnicos o sin valor directo para la preparación objetivo.

## Qué se ha quitado

- Common core antiguo
- Common core nuevo 2026
- Proyectos no técnicos
- Contenido sin valor específico para la oposición o la formación de sistemas

## Cómo está organizada la ruta

- B1–B5: fundamentos en C, redes, criptografía, algoritmos y Python / IA
- B6–B9: hacking, binarios, procesos y shells, DevOps y kernel
- B10–B14: lenguajes, VM, web, móvil, gráficos, blockchain y compiladores
- B15: proyectos sin información fiable; requieren revisar el subject antes de empezar
- B16: Open Project
