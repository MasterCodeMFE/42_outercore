# Ruta 42 + Oposición TAI

> Una visión estructurada de la progresión de proyectos dentro de mi formación en 42, enfocada en la preparación de la oposición TAI.

## Resumen

Esta ruta está organizada por bloques y sigue un orden lógico desde los fundamentos de sistemas hasta áreas más avanzadas como redes, seguridad, kernel, IA, web, móvil, gráficos, blockchain y compiladores.

Se han excluido proyectos del common core antiguo y nuevo, además de contenidos no técnicos o sin valor directo para la preparación objetivo.

## Qué se ha quitado

- Common core antiguo
- Common core nuevo 2026
- Proyectos no técnicos
- Elementos sin valor específico para la oposición o la formación de sistemas

## Cómo está ordenada esta ruta

- B1–B5: fundamentos en C, redes, criptografía, algoritmos y Python / IA
- B6–B9: hacking, binarios, procesos y shells, DevOps y kernel
- B10–B14: lenguajes, VM, web, móvil, gráficos, blockchain y compiladores
- B15: proyectos sin información fiable; revisar el subject antes de empezar
- B16: Open Project
